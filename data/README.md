# Derived data

The `.npz` response matrices and their independent halves are not in this
repository: they are roughly 1-2 GB, which is past what a git repository should
carry. They are deposited with the archived release instead, and the DOI is
given in the paper's Data availability statement.

`../code/loaders/` rebuilds every one of them from the public deposits listed in
the top-level README, so this directory is reproducible rather than required.
